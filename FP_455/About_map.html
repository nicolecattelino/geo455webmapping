About This Map – GEO 455 Final Project Nicole Cattelino

Introduction, Motivation, and Objective

What is being mapped?

This web map visualizes hiking trails, parking accessibility, viewpoints, and park boundaries in Great Smoky Mountains National Park. It integrates trail difficulty, infrastructure capacity, and scenic observation points into a single interactive environment.

Intended audience

This map is designed for hikers, outdoor visitors, and trip planners who want to explore trail options based on difficulty and access conditions. It also supports users who are unfamiliar with the park and need spatial context before visiting.

Why this map matters

The map supports decision-making for hiking and park navigation by allowing users to compare trail difficulty, locate parking availability, and identify viewpoints. It helps users plan visits more efficiently by combining recreational and logistical information in one interactive tool.

Core Interactions

Map Interactivity
  • Basemap toggle: Switch between USGS Imagery and Esri Topographic basemaps.
  • Home button: Returns the map to the original park extent.
  • Popups: Click features to view trail, parking, or viewpoint information.
  • Thematic layers: Toggle trails, parking, and viewpoint layers.
  • Search tool: Locate trails by name and zoom directly to them.
  • Clustering: Parking points are clustered to improve readability and performance.

Data Used and Methodology

Datasets
  • Trails and park infrastructure – National Park Service Open Data Portal
  • Parking lots – National Park Service Open Data Portal
  • Viewpoints – National Park Service Open Data Portal
  • Trail difficulty – manually compiled using AllTrails-based research
  • Basemaps – Leaflet basemap providers
Data processing
  1. Joined trail difficulty CSV to NPS trail shapefile using trail names
  2. Cleaned and standardized attribute fields
  3. Calculated parking capacity from multiple fields
  4. Applied graduated symbology for parking data
  5. Converted vector layers to GeoJSON for web use

Figure 1. Project workflow diagram.

Web delivery

All vector datasets are delivered as GeoJSON and rendered using Leaflet. Basemaps and external services are accessed via tile layers. The final application is hosted on GitHub Pages as an interactive web map.

Project Summary

Significance and what works well

This project successfully integrates multiple spatial datasets into a single interactive environment that supports real-world decision-making for park visitors. The combination of trail difficulty classification, parking accessibility, and viewpoint visualization creates a comprehensive understanding of both recreational opportunities and infrastructure constraints within Great Smoky Mountains National Park.

The strongest aspects of the map include its clear visual hierarchy, intuitive layer controls, and responsive interactivity such as search, popups, and clustering. Together, these elements allow users to explore the park efficiently without being overwhelmed by dense spatial data.

Strengths
  • Clear visual hierarchy using trail difficulty color coding
  • Interactive tools including search, clustering, and popups
  • Integration of trails, infrastructure, and viewpoints
  • Responsive layout with supporting information panel
Limitations
  • Incomplete imagery coverage for some viewpoints
  • Search interaction can temporarily increase visual complexity
  • No dedicated elevation (DEM) visualization layer
  • Clustering introduces abstraction at small scales
Next steps
  • Improve consistency of viewpoint imagery or add placeholders
  • Refine search behavior to reduce temporary layer overload
  • Enhance legend clarity for graduated parking symbols
  • Consider adding hillshade or elevation-based visualization
