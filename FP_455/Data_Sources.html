Data Sources – GEO 455 Final Project Nicole Cattelino

Data Sources Overview

This page documents all spatial and non-spatial datasets used in the creation of the Great Smoky Mountains National Park web map. All datasets were processed and standardized in ArcGIS Pro before being exported as GeoJSON for web use.

Trail Data

  • National Park Service (NPS) Trails Dataset
    Source: U.S. National Park Service Open Data Portal
    https://public-nps.opendata.arcgis.com/
  • Trail Difficulty Classification (Custom Attribute)
    Derived from external recreation sources (e.g., AllTrails descriptions) and manually assigned in ArcGIS Pro.

Parking Data

  • Parking Locations Dataset
    Source: National Park Service Open Data Portal
    https://public-nps.opendata.arcgis.com/
  • Parking Capacity Field Calculation
    Parking capacity values were calculated by summing available attribute fields in ArcGIS Pro to create a single standardized field for graduated symbology. Defined interval data classification was used to determine the size of each symbol.

View Tower Data

  • Viewpoint / Fire Tower Locations
    Source: National Park Service Open Data Portal
    https://public-nps.opendata.arcgis.com/
  • Viewpoint Images
    Images sourced from Wikimedia Commons (Creative Commons licensed). Some viewpoints do not have available imagery and are labeled accordingly in the popup interface.

Basemap and Reference Layers

  • USGS Imagery Basemap
    U.S. Geological Survey – National Map Services
    https://leaflet-extras.github.io/leaflet-providers/preview/
  • Esri World Topographic Map
    Esri Basemap Services
    https://leaflet-extras.github.io/leaflet-providers/preview/
  • Minimap layer
    https://leafletjs.com/plugins.html

Data Processing and Web Delivery

  • All vector datasets were cleaned and standardized in ArcGIS Pro.
  • Attribute fields were joined, calculated, and simplified for web performance.
  • Parking data was classified using natural breaks for graduated symbol mapping.
  • All spatial layers were exported as GeoJSON files.
  • The final web map was built using Phoenix Code and hosted via GitHub Pages.

All datasets were used for academic purposes in GEO 455 Web Mapping.
